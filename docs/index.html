03 / THE WHOLE API

Three inputs.
One next index.

Use a positive integer cycle size and a non-negative current index for array indexing.

Read the full documentation ↗
cyclicNext(max, curr = 0, inc = 1)
cyclicNext parameters
ParameterDefaultWhat it does
maxrequiredNumber of positions in the cycle
curr0Your current position
inc1How far to move forward

Returns (curr + inc) % max. Negative values retain their sign; a zero bound returns NaN. v1 keeps this behavior for compatibility. The visual playground limits cycle sizes to 1–24; the library does not.

04 / THE COMPANION

Need to go backward?

cyclic-prev moves to the previous index and wraps from the first position to the last.

Try the cyclic-prev playground ↺
npm install cyclic-next cyclic-prev
const cyclicNext = require('cyclic-next');
const cyclicPrev = require('cyclic-prev');

cyclicNext(5, 4); // 0: forward to the first
cyclicPrev(5, 0); // 4: backward to the last

Both packages ship CommonJS, ES modules, and TypeScript declarations with zero runtime dependencies. Their edge cases differ: cyclic-next v1 preserves JavaScript remainder behavior; cyclic-prev validates safe integers and normalizes the result into [0, max).
