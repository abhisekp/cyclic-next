# Changelog

## 1.1.0

- Preserve the published v1 callable API, add named/default imports, and retain legacy `lib` and `dist` paths.
- Add TypeScript declarations and an explicit native ES module entry.
- Keep Node 4+ runtime support and all JavaScript remainder edge cases.
- Remove runtime dependencies and replace the obsolete development toolchain.
- Add GitHub Actions for cross-platform CI, compatibility checks, Pages deployment, and token-free npm releases.
- Add an interactive offline playground and practical README examples (issues #2 and #3).
